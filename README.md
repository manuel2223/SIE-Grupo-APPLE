# SAEL — Diputación de Cádiz

Aplicación web desarrollada para optimizar la creación, gestión y automatización de documentos administrativos dentro del entorno de oposiciones y gestión técnica del **SAEL (Servicio de Asistencia a Entidades Locales)**.

---

## ✨ Descripción

Este proyecto engloba un conjunto de herramientas diseñadas para digitalizar y automatizar procesos clave:

- 📝 Generación de exámenes personalizados
- 📄 Creación automática de documentos oficiales
- 🔄 Sincronización inteligente de datos entre tablas

Todo ello orientado a mejorar la eficiencia, reducir errores manuales y facilitar el trabajo administrativo.

---

## 🚀 Funcionalidades principales

### 🧠 Generador de Exámenes

Permite crear exámenes de forma dinámica a partir de una interfaz sencilla:

- Definición de preguntas
- Configuración de respuestas (tipo test, abiertas, etc.)
- Estructuración del contenido del examen
- Exportación automática a PDF listo para impresión

> Ideal para procesos de oposiciones adaptados a distintos puestos.

---

### 📑 Generador de Oficios de Remisión

Herramienta auxiliar para la generación de documentos administrativos:

- Relleno automático de plantillas
- Introducción de datos mediante formulario
- Generación de documentos oficiales en formato PDF

> Reduce el tiempo dedicado a tareas repetitivas y evita errores de formato.

---

### 🔗 Sincronización de Datos

Sistema de automatización para mantener coherencia entre tablas:

#### ⚙️ Funcionamiento

- Detecta cambios en la tabla de municipios  
- Replica automáticamente la información en la tabla de técnicos  
- Mantiene consistencia en una relación 

> Evita desajustes de datos y sincronizaciones manuales.

---

## 🛠️ Tecnologías
### 🧠 Exámenes
- Frontend: HTML / CSS / JavaScript
- Backend: Django
- Generación PDF: WeasyPrint
- Base de Datos: SQLit / Mysql

### 📑 Oficios de Remisión
- Aplicación: Python
- Datos: Excel
